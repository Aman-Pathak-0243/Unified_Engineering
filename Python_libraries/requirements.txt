# --- Version notes ----------------------------------------------------------
# pandas 3.x is a deliberate choice, not an accident. The notebooks teach the
# current behaviour of four things that changed in 3.0, and they say so where
# it matters:
#
#   * text columns have a real `str` dtype (was the catch-all `object`)
#   * copy-on-write is always on, so chained assignment never writes through
#   * DataFrame.applymap was removed; DataFrame.map replaces it
#   * fillna(method="ffill") was removed; use .ffill() / .bfill()
#
# You do NOT have to install this to use the notebooks. All four were also
# executed end to end against pandas 2.2.2 / numpy 1.26.4 / matplotlib 3.9.2 --
# roughly what Google Colab ships -- and every cell runs there too. The cells
# whose behaviour genuinely differs detect the installed version and report
# what it does; the rest of the difference is cosmetic dtype labels
# (`object` for `str`, `datetime64[ns]` for `[us]`).
#
# Install this pinned set when you want your screen to match the outputs
# stored in the notebooks exactly -- useful when projecting in a classroom.
#
# Seeded random data is stable across numpy 1.26 and 2.x — the generated
# datasets, and every figure quoted in the prose, are identical on both.
